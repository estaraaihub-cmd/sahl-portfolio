# Muhammed Sahl — AI Content Creator & Visual Storyteller

Personal portfolio website for **Muhammed Sahl**, AI Content Creator and AI Creative Director.

## 🚀 Overview
- **Aesthetic**: Obsidian dark mode with glowing ember/warm amber accents.
- **Features**:
  - Interactive hero canvas with visual storytelling categories
  - Detailed service capabilities with hover zoom and glowing borders
  - Portfolio project showcases with 4K video player lightbox modal
  - AI Production Stack & Tools
  - Direct contact integrations (Email, WhatsApp, Instagram)
- **Live Local Preview**: Built with modern vanilla HTML5, CSS3, and JavaScript.

## 💻 Running Locally
You can run this project with any local server, or use the included PowerShell server:
```powershell
powershell -ExecutionPolicy Bypass -File server.ps1
```
Then visit: `http://localhost:8080/`
