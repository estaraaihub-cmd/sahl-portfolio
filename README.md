# Muhammed Sahl — AI Content Creator & Visual Storyteller Portfolio

A modern personal portfolio website crafted for **Muhammed Sahl**, combining dark obsidian aesthetics with warm ember/orange cinematic lighting, glassmorphism, interactive project showcases, and a multi-engine AI creative pipeline.

---

## 🌟 Visual & Design Identity
- **Design Inspiration**: Warm amber/ember neon gradients, deep obsidian shadows, and cinematic minimalism inspired by high-concept AI filmmaking and modern creative studio aesthetics.
- **Color Palette**: Rich Obsidian (`#08080a`), Warm Ember (`#ff5e1e`), Sunset Amber (`#ff8a00`), Frosted Glass panels.
- **Typography**: Clean, bold grotesque display font pairs (`Plus Jakarta Sans` & `Space Grotesk`).
- **Interactive Lightbox**: Interactive simulated 4K video player with playback toggle, timecode ticker, sound simulation, and prompt breakdown for every featured project.

## 🚀 How to Run & View Locally

This project is completely self-contained with **zero dependencies** or build steps required.

### Quick Start:
1. Double-click `index.html` to open it in your default web browser (Chrome, Edge, Brave, Firefox, Safari).
2. Or in PowerShell / Terminal:
   ```powershell
   Start-Process index.html
   ```

---

## 🌐 Deploy to the Web (Free)

### Option 1: GitHub Pages
1. Push this folder to a GitHub repository.
2. Go to **Settings > Pages**.
3. Under **Branch**, select `main` and `/ (root)`.
4. Click **Save** — your site is live in seconds!

### Option 2: Vercel / Netlify
1. Drag and drop the `Portfolio` folder into [Netlify Drop](https://app.netlify.com/drop) or import from GitHub on [Vercel](https://vercel.com).
2. Your portfolio will be live with an automatic SSL certificate.
